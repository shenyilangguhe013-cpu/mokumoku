@@@ISSUE 2 | 2026-08-05 | インフレと消費者物価指数
テーマ：インフレ・デフレと消費者物価指数（CPI）
「同じものを買うのにいくら要るか」を測る物差し、CPIを図で整理します。

■1. 本日の一問

消費者物価指数（CPI）の説明として、最も適切なものを選びなさい。
ア　家計が買うモノとサービスの値段を加重平均して、1つの数字にした指数
イ　企業どうしで取引される卸売物価の指数
ウ　国内で1年間に生まれた付加価値の合計
エ　輸入品だけの値段の動きを示す指数
【解答＝ア】
標準の買い物カゴ → 去年の同じ月と値段を比べる → 上昇率がCPI
CPI：総務省統計局が毎月公表する
PPI：企業間で取引される卸売物価
つながり：第1回の実質GDP → 値上がり分を測るのがCPI

■2. つながりの流れ図

中東で原油が急騰 → 油価連動のLNG契約 → 時間差で電気料金に反映 → CPIが上向きに
中東の原油高 → 日欧で物価が上向く → 日銀とECBが利上げ → 米国は据え置き
米財務長官が日銀に言及 → 追加利上げの観測 → 日米の金利差が縮むとの予想 → 円が買われる
為替は実際の政策変更より先に、予想で動きます。

■3. 年号・数字コーナー

2026年2月末 / ホルムズ海峡をめぐる緊迫で原油価格が急騰
2026年6月 / 日銀が利上げし、全国コアCPIは前年同月比+1.6％
2026年7月31日 / 東京都区部の7月コアCPIが+1.9％へ加速
2026年8月3日 / 日米の協調介入でドル円が155円台へ
約600品目 / 全国CPIが値段を調べる品目の数
113.6 / 2026年6月の全国CPI（2020年＝100）
+1.6％ / 2026年6月の全国コアCPI（5か月連続の2％割れ）

■4. 国際比較・外部の視点

国・地域 / 直近の物価 / 政策金利
日本 / コアCPI +1.6％（6月） / 1.00％
米国 / 総合+3.5％・コア+2.6％（6月） / 3.50〜3.75％
ユーロ圏 / +2.9％（7月速報） / 2.25％（預金金利）

読み取り① 日欧は原油高で利上げ、米国は据え置きと、向きが割れている。
読み取り② 中国はCPIよりPPIが高く、需要不足のデフレ圧力が残る。

■5. 3行まとめ

CPIは家計の標準的な買い物カゴの値段で、日本のコアは+1.6％と2％割れが続く。
為替は実際の政策より、金利差の予想で動く。米財務長官の発言で円が買われた。
日欧は利上げ、米国は据え置き、中国はデフレ圧力と、世界の物価は向きが割れている。

■6. 試験対策の視点

コアの定義：日本は生鮮除く、コアコアは生鮮とエネルギー除く
指数と上昇率：113.6は水準、+1.7％は前年同月比
2％目標の理由：統計の上振れ癖と、金利を下げる余地の確保
外務省の視点：円安はODAを削り、原油高は中東外交の重みを増す
経産省の視点：油価連動LNGで電気料金が上振れ、多消費産業に影響

■7. 今日の復習クイズ

問1　日本の「コアCPI」が除いているものはどれか。
ア　エネルギー
イ　生鮮食品
ウ　家賃
エ　サービス価格
【解答＝イ】日本のコアCPIは生鮮食品を除く総合です。

問2　2026年6月の全国コアCPI（前年同月比）に最も近いものはどれか。
ア　＋0.6％
イ　＋1.6％
ウ　＋2.6％
エ　＋3.6％
【解答＝イ】+1.6％で、2％割れが5か月続いています。

問3　（第1回）景気の良し悪しを見るのに使うGDPはどれか。
ア　名目GDP
イ　実質GDP
ウ　ドル建てGDP
エ　一人あたりGDP
【解答＝イ】実質GDPは値上がり分を差し引いた額です。

問4　（第1回）ドル円の数字が上がると、何が起きているか。
ア　円高
イ　円安
ウ　ドル安
エ　金利低下
【解答＝イ】1ドルに必要な円が増えるので円安です。

問5　（第1回）GDPを家計にたとえると、何にあたるか。
ア　貯金
イ　借金
ウ　年収
エ　家賃
【解答＝ウ】その年に稼いだ額なので、国の年収にあたります。
