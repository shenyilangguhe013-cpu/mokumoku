@@@ISSUE 11 | 2026-08-13 | エネルギー輸入依存
テーマ：エネルギー輸入依存
自給率16.4％の国が、海の向こうの出来事で電気代と円安を同時に受ける仕組みを図で整理します。

■1. 本日の一問

日本のエネルギー自給率（2024年度）として、最も近いものを選びなさい。
ア　16.4％
イ　36.4％
ウ　56.4％
エ　76.4％
【解答＝ア】
自給率：使うエネルギーのうち、自国で作れた割合
日本：16.4％で、8割以上を輸入に頼る
問題の核心：値段を自分で決められないこと

■2. つながりの流れ図

中東の戦いでホルムズ海峡が封鎖 → 原油が上がる → 輸入代金のドルが増える → 円を売ってドルを買う → 円安
円安 → 輸入代金がさらに増える → 電気代・物価が上がる → 家計と企業の負担が増える
備蓄は約8か月分 → すぐには足りなくなる状況でない → ただし長期化すれば別
資源高と通貨安が同時に来て、二重に痛みます。

■3. 年号・数字コーナー

2024年度 / 日本のエネルギー自給率は16.4％
2026年2月末 / 中東の戦いが始まり、イランがホルムズ海峡を封鎖
2026年8月12日 / トランプ米大統領が「海峡を完全に掌握」と発言
2026年8月12日 / 7月の米CPIは前年比+3.4％、コアは+2.5％
2026年8月 / 石油の備蓄は約8か月分
80％超 / 化石燃料への依存度
約9割 / 輸入原油のうちホルムズ海峡を通る割合
25％ / 原油が80ドルから100ドルになったときのドル支払いの増え方

■4. 国際比較・外部の視点

国 / 自給率 / 主な柱
米国 / 188.6％ / シェールの石油・ガス
フランス / 67.5％ / 原子力
ドイツ / 49.3％ / 再エネ・石炭
日本 / 16.4％ / G7で最も低い
読み取り① 米国は使う量より多く作り、余ったエネルギーを外交の道具にできる。
読み取り② フランスは原子力で、資源がなくても自給率を上げられると示した。

■5. 3行まとめ

日本のエネルギー自給率は16.4％で、8割以上を輸入に頼る。
輸入原油の約9割はホルムズ海峡を通り、封鎖の長期化が原油を押し上げる。
原油高は「実需の円売り」で円安を招き、資源高と通貨安が重なる。

■6. 試験対策の視点

エネルギー自給率：使うエネルギーのうち自国で作れた割合
実需の円売り：支払いのために円を売ってドルを買うこと
ホルムズ海峡：中東の石油・LNGの出口。日本の原油の約9割
外務省の視点：産油国との資源外交と、脱石油への協力が保険
経産省の視点：調達先の分散、再エネ、原発再稼働で自給率を上げる

■7. 今日の復習クイズ

問1　「エネルギー自給率」の説明として正しいのはどれか。
ア　輸入したエネルギーの総額
イ　使うエネルギーのうち、自国で作れた分の割合
ウ　発電量に占める再エネの割合
エ　海外に売っているエネルギーの割合
【解答＝イ】石油も太陽光も原子力も合わせて計算します。

問2　原油が値上がりすると円が安くなりやすい理由はどれか。
ア　日銀が原油を買うために円を売るから
イ　外国人が日本株を売るから
ウ　輸入代金のドルが増え、その分円が売られるから
エ　政府が円安に誘導するから
【解答＝ウ】支払いのための円売りで、実需の円売りと呼びます。

問3　（第3回）金利1％で借り、1年で物価が2％上がった。実質金利はいくらか。
ア　プラス3％
イ　プラス1％
ウ　0％
エ　マイナス1％
【解答＝エ】実質金利は1％−2％＝マイナス1％で、借り手が有利です。

問4　（第7回）2026年6月の有効求人倍率は何倍か。
ア　0.98倍
イ　1.08倍
ウ　1.18倍
エ　1.38倍
【解答＝ウ】1倍を超え、求人のほうが求職者より多い状態です。

問5　（第10回）潜在成長率を決める3つの要素の組み合わせはどれか。
ア　労働・資本・TFP
イ　輸出・輸入・為替
ウ　税金・国債・補助金
エ　物価・賃金・金利
【解答＝ア】人、設備、工夫の3つが経済の上限を決めます。
