テーマ：産業構造の変化
働く場所は第3次産業、稼ぐ場所は製造業。日本の稼ぎ方の地図を図で整理します。

■1. 本日の一問

日本のGDPに占める割合が最も大きい産業はどれか。
ア　第3次産業で約7割
イ　製造業で約5割
ウ　第1次産業で約4割
エ　建設業で約6割
【解答＝ア】
第1次産業：農業・漁業など。1％台
第2次産業：製造業・建設業。製造業は約2割
第3次産業：小売・飲食・金融・情報。約7割

■2. つながりの流れ図

米国は個人消費が約7割 → 小売売上高が弱い → 景気が弱いと見られる → 利下げ予想が強まる → ドルが売られる
半導体と自動車の輸出が好調 → 貿易収支が黒字に転じる → 経常収支が過去最大に → サービス収支は赤字のまま
日銀の9月利上げ観測 → 日米の金利差が縮むと見られる → 円が買われる
国内の働き口は第3次産業、外貨を稼ぐ場所は製造業です。

■3. 年号・数字コーナー

2022年 / 世界銀行による製造業のGDP比の国際比較
2026年上半期 / 経常収支は17兆4292億円の黒字で過去最大
2026年8月10日 / 財務省が上半期の国際収支を発表
2026年8月14日 / 米小売売上高が前月比−0.6％。ドル円は一時158.60円
約7割 / 日本のGDPに占める第3次産業の割合
−1兆8223億円 / サービス収支の赤字。2438億円拡大
+7421億円 / 上半期の貿易収支（前年は1兆4636億円の赤字）

■4. 国際比較・外部の視点

国 / 製造業のGDP比 / 特徴
中国 / 28％ / 世界の工場
日本 / 20％ / 先進国では高い
ドイツ / 18％ / 日本と並ぶモノづくり
米国 / 11％ / サービスと消費に寄る
読み取り① 日本の20％はドイツと並び、先進国では高いほうである。
読み取り② 米国は11％と低く、小売や雇用のデータが相場を大きく動かす。

■5. 3行まとめ

産業構造は、どの仕事でいくら稼ぐかの内訳で、日本は第3次産業が約7割だ。
2026年上半期の経常黒字は17兆4292億円で過去最大。サービス収支は赤字だ。
米国はGDPの約7割が個人消費で、小売売上高が弱いとドルが売られる。

■6. 試験対策の視点

産業構造：どの仕事でいくら稼ぐかの内訳
サービス経済化：製造業から第3次産業へ比重が移ること
個人消費：米国のGDPの約7割。弱いと利下げ予想が強まる
外務省の視点：特定品目・相手への集中は弱点。売り先を分散する交渉が要る
経産省の視点：デジタルへの支払いがサービス赤字の原因。国内産業の育成が課題

■7. 今日の復習クイズ

問1　第3次産業に当たる仕事はどれか。
ア　まぐろの漁
イ　自動車工場での組み立て
ウ　コンビニでの販売
エ　ビルの建設
【解答＝ウ】サービスを売る仕事です。アは第1次、イとエは第2次です。

問2　米国の小売売上高が予想を下回るとドルが売られやすい理由はどれか。
ア　小売店が輸入を減らすから
イ　消費が弱く、利下げ予想が強まり金利が下がるから
ウ　小売業がドルを外貨に替えるから
エ　輸出が増えるから
【解答＝イ】米国はGDPの約7割が個人消費で、消費が弱いと金利低下を通じてドルが売られます。

問3　（第2回）コアCPIとは何か。
ア　食料とエネルギーの両方を除いたCPI
イ　生鮮食品を除いたCPI
ウ　企業どうしの取引価格の指数
エ　輸入品だけの物価指数
【解答＝イ】天候で動く野菜や魚を外し、物価の底の動きを見ます。

問4　（第5回）ビッグマック指数で、円は米ドルに対してどう評価されていたか。
ア　約5割の過大評価
イ　ほぼ適正
ウ　約1割の過小評価
エ　約5割の過小評価
【解答＝エ】480円対3.05ドルで、約50.5％の過小評価でした。

問5　（第9回）定期昇給とベースアップの違いはどれか。
ア　定期昇給は賃金表を上げ、ベアは個人の年齢分
イ　定期昇給は個人の年齢や勤続分、ベアは賃金表を上げる分
ウ　どちらも同じ意味
エ　定期昇給は正社員、ベアは非正規だけ
【解答＝イ】世代全体の水準を動かすのはベアです。
