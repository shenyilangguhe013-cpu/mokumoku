# もくもく部屋

一人だと勉強を後回しにしてしまう大学生向けの、スマホ用「もくもく学習」アプリです。
架空の大学生ライバルたちが同じ部屋で勉強している気配を再現し、ワンタップで勉強を始められることを目指しています。

`index.html` 1ファイルだけで完結しており、外部ライブラリやビルド手順は不要です（テストだけ `npm test` で動かします）。

## 画面と主な機能

下のタブバーに、部屋・タスク・一問一答・国際・ランキング・その他の6つがあります。

### 部屋
- **勉強の開始**: 一番上の「資格の勉強」をタップし、時間と科目（任意）・メモ（任意）を選んで始めます。目標時間を過ぎても自動終了せず「+◯分」と測り続け、「切り上げて終了する」で記録します。
- **ライバル**: 架空の大学生10人（うち1人は夜型）が、勉強中・休憩中・退室中を切り替えながら過ごします。動きは日付をシードにした疑似乱数で決まるので、同じ日にリロードしても一貫します。
- **連続入室日数（ストリーク）**: 「連続◯日入室中」を表示し、3・7・14・30・50・100・200日で特別なメッセージを出します。完了コマ数の累計が10・30・50・100・200・500に達したときは、お祝いのトーストを出します。
- **完了コマ数**: 科目を選んで終了すると、完了画面で「完了したコマ数」を入力できます。

### タスク
- **今日のタスク**: `data/today_tasks.json`（毎朝の自動作成。認証なしで取得）を、チェックボックス付きで表示します。見出し（`text`）と箇条書き（任意の `details`）、所要時間（`minutes`）を使い、「合計 約◯時間／残り 約◯時間」を出します。次の配信までは、最後に届いたタスクを表示し続けます。休養日（`isRestDay`）は専用の表示です。チェック状態は日付ごとに端末へ保存し、学習記録とは独立しています。
- **タスクから勉強を開始**: 各タスクの「▶ このタスクで勉強を始める」で、科目・所要時間・題名を引き継いでタイマーが始まります。予定の時間までやり切ると、そのタスクに自動でチェックが付きます。
- **今日／今週／今月**: `data/plan.json` の週の計画・月の計画を見られます（表示専用）。
- **GitHubに保存**: 学習記録とタスクのチェック状態を、まとめてGitHubに保存します（下の「GitHubへの保存」を参照）。
- **ミニテスト記録**: 水曜A・土曜Bなどの、分野別の正誤を記録します（`data/minitest_export.json`）。

### 一問一答
`data/ichimon/index.json` のデッキ（○×・めくりカード）を1枚ずつ解きます。デッキ・分野・出典・「間違えたカードだけ」などで絞り込めます。結果は端末に保存し、`data/ichimon_results.json` で端末間でも共有します。

### 国際（国際関係ブリーフ）
- `data/briefs/kokusai/` のブリーフを、一覧（新しい順）から開いて読みます。本文は全画面で、`sandbox="allow-scripts"` のiframeに表示します。欠番は灰色で、タップできません。
- **ブックマーク（★）・既読（✓）・続きから読む**: 端末ごとに保存します。6割まで読むか、問題に答えると既読になります。
- **全回検索**: 語で全回を検索し、開くと該当語を強調します。
- **正誤の記録**: 本文内の問題に答えると、`kokusai_quiz_v1` に追記します（`data/kokusai_quiz_export.json` にも保存）。
- **今日の復習**: ×の問題を、国際関係・一問一答の両方から、1→3→7→14日の間隔で出します。
- **まちがい集**: 国際関係・一問一答・ミニテストの×を一覧し、解き直せます（解説は解き直したあとに表示）。回ごとの正答率・弱点テーマ・絞り込みもあります。
- 「第◯回」のリンクは、同じ画面で一時表示し、戻ると元の位置に戻ります。

### ランキング
今日・今週の勉強時間ランキング（自分＋ライバル）と、今週と先週の曜日別比較グラフ（目盛り付き）を表示します。

### その他
- 記録の概要、**学習記録の手動追加**（前回の時間・科目を初期値にします）、履歴の**編集（✎）と削除（✕）**。
- **科目別の進捗**（進捗管理シート `data/progress.json` の値を優先）、**試験日**（入れると、試験までの日数・残りコマ数・必要なペースを表示）、**復習した時間**。
- **履修・バイト予定の写真登録**（`data/schedule_photos/` へ保存）。
- **GitHub連携**（トークンの登録）。

### 共通
- ヘッダー右上に、GitHubへの**保存状態**（保存中・保存済み・未保存で再試行）を表示します。ヘッダーには、試験日までの日数も出ます。
- 起動のたびにサーバー上の最新のコードを確認し、違えば1回だけ自動で再読み込みします（記録は消えません）。

## 使い方

1. `index.html` をスマホのブラウザで開きます（下記のGitHub Pagesでの公開が簡単です）。
2. 「部屋」タブで「資格の勉強」をタップし、時間を選んで始めます。
3. 終了すると、今日の合計勉強時間とともに労いメッセージが出ます。
4. 「ランキング」「国際」「一問一答」などは、タブから使います。

## GitHubへの保存（任意）

「その他」タブの「GitHub連携」に、このリポジトリ専用のPersonal Access Token（Fine-grained・Contents: Read and write権限のみ）を登録すると、学習記録などをこのリポジトリへ直接コミットします。

| 内容 | 保存先 |
|---|---|
| 学習記録 | `data/mokumoku_export.json` |
| タスクのチェック状態 | `data/today_tasks_status.json` |
| ミニテスト記録 | `data/minitest_export.json` |
| 一問一答の結果 | `data/ichimon_results.json` |
| 国際関係ブリーフの正誤 | `data/kokusai_quiz_export.json` |
| 予定の写真 | `data/schedule_photos/` と `data/schedule_meta.json` |

- 保存のときは、リポジトリ上の記録を読み込み、この端末の記録とIDで重複なく統合してから書き込みます（記録の少ない端末から保存しても、他の端末の過去の記録は消えません。端末で削除した記録は統合されません）。
- 学習が終わったとき・手動で記録を追加したときは、自動でも保存します（「タスク」タブのカードで、オフにできます）。
- トークンは端末の localStorage に保存されます。端末を紛失・売却・共有するときは、GitHub側でトークンを失効させてください。「トークンが無効」と返されたときは、「その他」タブに作り直しの案内を出します。

## テスト

`npm ci` → `npx playwright install chromium` → `npm test` で、実ブラウザ（headless Chromium）がアプリを開き、主要な操作でコンソールエラーが出ないことを確認します。GitHub Actions の CI（`.github/workflows/ci.yml`）も、同じテストを動かします。

## GitHub Pagesでの公開手順

1. このリポジトリのGitHub設定画面で **Settings > Pages** を開きます。
2. 「Build and deployment」の Source を **Deploy from a branch** に設定します。
3. Branch を公開したいブランチ（例: `main`）、フォルダを `/(root)` に設定して保存します。
4. しばらく待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。
5. スマホでそのURLを開き、ブラウザの共有メニューから「ホーム画面に追加」を選ぶと、アプリのように使えます。

## 基準値について

`index.html` 冒頭の `BASELINE_AVG_MINUTES` は、大学生の平均的な1日の学習時間を表す仮の基準値です。ライバルの学習量は、この基準値に一人ひとり0.7〜1.5倍程度の個人差と日ごとのばらつきを掛け合わせて算出しています（実際のデータに後で差し替える前提の値です）。
