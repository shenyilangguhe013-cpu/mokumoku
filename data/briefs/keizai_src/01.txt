@@@ISSUE 1 | 2026-08-05 | GDP（名目・実質）
テーマ：GDP（名目・実質）
経済のいちばん基本の物差し「GDP」を、円安とのつながりも含めて図で整理します。

■1. 本日の一問

GDP（国内総生産）の説明として、最も適切なものを選びなさい。
ア　一国で1年間に新しく生み出された付加価値の合計
イ　一国が持っている資産の合計
ウ　政府が抱える借金の合計
エ　企業の売上高を単純に足し合わせた額
【解答＝ア】
パンの売値200円 → 小麦の仕入れ80円を引く → 付加価値120円 → 国じゅうで合計 → GDP
GDP：国の年収にあたる指標
付加価値：売上から仕入れを引いた新しい価値

■2. つながりの流れ図

日本1.0％ → 米国3.50〜3.75％ → 金利差が約2.5〜2.75％ → 円売り・ドル買い → 円安
円安が進む → ドル換算のGDPが縮む → 2026年にインドに抜かれる → 世界5位へ後退
輸入が増える → GDPの計算でマイナス → 貿易赤字が成長を押し下げる
円建てで伸びても、1ドル＝157円で割るとドル建ては小さくなります。

■3. 年号・数字コーナー

2011年 / 東日本大震災後に、日米が協調して円買い介入を実施
2023年 / 日本の名目GDPがドイツに抜かれ、世界3位から4位に後退
2026年4〜5月 / 日本単独で過去最大の11.7兆円の円買い介入
2026年6月 / 日銀が0.25％幅の利上げをして政策金利を1.0％に
2026年7月31日 / 日米が15年ぶりに協調して円買い介入を実施
2026年8月17日 / 内閣府が4〜6月期GDPの1次速報を公表する予定
4兆4,636億ドル / 2026年の日本の名目GDP予測（インドは4兆5,056億ドル）
11.7兆円 / 2026年4〜5月の円買い介入の額（過去最大）
5.6倍 / 米国からの原油輸入数量の増え方（2026年6月）

■4. 国際比較・外部の視点

中央銀行 / 政策金利 / 7月の判断
日本銀行 / 1.00％ / 据え置き（6月に利上げ）
FRB（米） / 3.50〜3.75％ / 5会合連続で据え置き
ECB（欧） / 未確認 / 据え置き（6月に利上げ）
読み取り① 同じ原油高でも、日米欧で政策の向きがそろっていない。
読み取り② 日米の金利差が大きく、円が買われにくい構造が続く。

■5. 3行まとめ

GDPは国が1年に新しく生んだ付加価値の合計で、国の年収にあたる。
日米の金利差が円安の根本原因で、協調介入は金利差までは動かせない。
円安でドル建てGDPが縮み、日本は2026年に世界5位へ後退する見通し。

■6. 試験対策の視点

名目と実質：景気は実質、国際比較は名目で見る
年率換算：3か月のペースが1年続くと仮定した数字
ドル建ての罠：円安だとドル換算のGDPは縮む
外務省の視点：円安はODA予算の実質購買力を削る
経産省の視点：円安は輸出に追い風、原材料高は中小に打撃

■7. 今日の復習クイズ

問1　景気の良し悪しを見るときに使うGDPはどれか。
ア　名目GDP
イ　実質GDP
ウ　一人あたりの貯蓄額
エ　ドル建ての名目GDP
【解答＝イ】実質GDPは値上がり分を差し引くので、景気を見るときに使います。

問2　四半期GDPの「年率＋2.4％」の説明として正しいものはどれか。
ア　その3か月で実際に2.4％伸びた
イ　その3か月のペースが1年続くと仮定した数字
ウ　前の年の同じ月と比べた伸び率
エ　1年間の実際の伸び率
【解答＝イ】実際の3か月の伸びは0.6％程度で、年率換算すると大きく見えます。

問3　ドル円が「1ドル＝157円」から「160円」に動いたとき、正しいものはどれか。
ア　円高になった
イ　円安になった
ウ　円の価値は変わらない
エ　ドルの価値が下がった
【解答＝イ】1ドルを買うのに必要な円が増えるので、円安です。

問4　2026年7月31日の日米協調介入は、何年ぶりだったか。
ア　3年ぶり
イ　5年ぶり
ウ　10年ぶり
エ　15年ぶり
【解答＝エ】東日本大震災後の2011年以来、15年ぶりの協調介入でした。

問5　円安で日本のドル建て名目GDPが縮み、2026年に日本を上回ると見込まれた国はどれか。
ア　ドイツ
イ　インド
ウ　ブラジル
エ　韓国
【解答＝イ】日本は2023年にドイツに抜かれ、2026年にはインドに抜かれて5位になる見通しです。
