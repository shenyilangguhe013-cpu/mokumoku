テーマ：ODAと開発金融
お金や技術を途上国に出す仕組みを、外交の道具として図で整理します。円安と米中の動きも合わせて見ます。

■1. 本日の一問

円安が続くと、ODAにどんな影響が出るか。
ア　同じ予算でも援助できる量が目減りする
イ　援助できる量が自動的に増える
ウ　援助にはまったく影響しない
エ　相手国の返済が免除される
【解答＝ア】
支払い：現地通貨や米ドルで払う場面が多い
円安：同じ円でも、手に入るドルが減る
対策：民間資金を呼び込むPPPを新設

■2. つながりの流れ図

円安が続く → 同じ予算で援助できる量が減る → 民間資金を呼び込む → PPPでインフラ整備を進める
日本が提案する → オファー型ODAを増やす → 相手国との関係が強まる → 経済外交の武器になる
中東の緊張が和らぐ → 有事のドル買いが巻き戻る → ドルが売られる → ドル円は159円前後で上下
援助は慈善だけでなく、関係を強める外交の道具でもあります。

■3. 年号・数字コーナー

2000〜2021年 / 中国の援助・融資は合計1.34兆ドル
2024年 / 日本のODA実績は167.7億ドルで4位
2026年度 / 無償資金協力は前年度比1.1％増の1,531億円
2026年8月25日 / ドル円が159円49銭まで上がったあと失速
2026年8月26日 / ドル円は158円88銭〜159円26銭で推移
2027年度 / 外務省がPPPの新設を概算要求。10億円超
167.7億ドル / 日本のODA実績（世界4位）
0.39％ / ODAのGNI比。DAC加盟国で13位

■4. 国際比較・外部の視点

国 / 規模・順位 / 最近の動き
日本 / 実績4位・GNI比は13位 / オファー型ODAとPPPを推進
米国 / これまで世界最大級 / USAIDを解体し大幅縮小
中国 / 2000〜2021年に1.34兆ドル / 一帯一路の融資は減少傾向
読み取り① 日本は総額で上位でも、経済規模に対する比率では中位にとどまる。
読み取り② 米国が縮小し中国が減速するいま、援助の質で差をつけられる余地が広がる。

■5. 3行まとめ

ODAは慈善だけでなく、相手国との関係を強める外交の道具でもある。
円安は、援助に使えるお金の実質的な目減りにつながる。
米国の縮小と中国の減速のはざまで、日本の援助の立ち位置が問われる。

■6. 試験対策の視点

ODA：政府が途上国に資金や技術を提供する仕組み
オファー型ODA：要請を待たず、日本から提案する援助
PPP：政府と民間企業が協力して進める仕組み
外務省の視点：中国の債務のわなへの警戒の中、質の高い援助で差別化
経産省の視点：PPPで日本企業のインフラ輸出と資源国との調達に役立つ

■7. 今日の復習クイズ

問1　ODA（政府開発援助）とは何を指すか。
ア　政府が発展途上国に資金や技術の協力を行う仕組み
イ　中央銀行が短期金利を上下させる政策
ウ　企業どうしが互いの株式を持ち合う仕組み
エ　国が輸入品にかける税金の制度
【解答＝ア】イは金融政策、ウは株式持ち合い、エは関税の説明です。

問2　中東の緊張が和らいだ26日、ドルが売られやすくなった理由はどれか。
ア　日銀が追加の利上げを決めたから
イ　訪日客による円買いが急増したから
ウ　不安なときに買われる有事のドルへの需要が薄れたから
エ　財務省がドル売り円買いの介入を実施したから
【解答＝ウ】緊張が和らぐと、安全資産としてのドル買いが巻き戻ります。

問3　（第19回）2024年の日本の時間あたり労働生産性は、OECD38か国中で何位か。
ア　5位
イ　15位
ウ　22位
エ　28位
【解答＝エ】時間あたり60.1ドルで、特にサービス業の弱さが指摘されています。

問4　（第14回）米国が日本からの輸出品に追加関税をかけたとき、実際に納めるのは誰か。
ア　日本の輸出企業
イ　米国の輸入業者
ウ　日本政府
エ　世界貿易機関
【解答＝イ】関税は輸入する側の業者が、自国の税関に納めます。

問5　（第2回）コアCPIの説明として正しいのはどれか。
ア　生鮮食品を除き、物価の基調をつかみやすくした指標
イ　輸入品だけを対象にした物価指数
ウ　株価の変動だけを反映した指数
エ　公共料金だけを集めた指数
【解答＝ア】生鮮食品は天候で値段が大きく振れるため、これを除きます。
