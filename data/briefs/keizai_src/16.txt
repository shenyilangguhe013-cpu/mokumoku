@@@ISSUE 16 | 2026-08-18 | 経済安全保障と輸出管理
テーマ：経済安全保障と輸出管理
値段で競う時代から、売るか売らないかの時代へ。交渉の道具の変化を図で整理します。

■1. 本日の一問

日本が輸入するレアアースのうち、中国産のおよその割合はどれか。
ア　約6割
イ　約1割
ウ　約3割
エ　ほぼ全量
【解答＝ア】
デュアルユース：軍にも民間にも使えるもの
レアアース：スマホや電気自動車のモーター磁石の材料
急所：使う量は少なくても、なければ製品が作れない

■2. つながりの流れ図

中国が許可制でしぼる → 磁石の材料が届かない → モーターが作れない → 自動車や家電が止まる
弱いGDPが出る → 円は売られにくい → 日銀の早期利上げ観測が残る → 実需の円買いが出て円は堅調
日本の弱みは上流 → 掘る・精錬する工程が国内に乏しい → 輸入先を増やす → 使う量を減らす・リサイクル
関税は値段、輸出管理は売れるかどうかを決める道具です。

■3. 年号・数字コーナー

2026年1〜6月 / 中国の対日レアアース輸出が前年同期比で5割減
2026年3〜4月 / 対日輸出が8割超減った月もあった
2026年8月17日 / 4〜6月期GDPは年率+1.1％（予想は+2.2％）
2026年8月17日 / 午前10時のドル円は159円01銭前後で円堅調
2026年8月18日 / ドル円は159円前後の予想。FOMC議事要旨待ち
約6割 / 日本のレアアースの中国依存
約6,600億円 / 輸入が3か月止まったときの損失の試算
約2.6兆円 / 輸入が1年止まったときの損失の試算

■4. 国際比較・外部の視点

国・地域 / 主な道具 / ひとこと
中国 / レアアースの輸出許可制 / 個別許可が中心
米国 / エンティティリスト / 取引禁止の相手を名簿にする
EU・ドイツ / 重要原材料の調達先分散 / 特定国への偏りを下げる
日本 / 外為法の許可と供給網の多元化 / 掘る・精錬する工程が乏しい
読み取り① どの国も、自分が持つものを交渉の道具に使い始めている。
読み取り② 日本の弱みは上流で、調達先とリサイクルが頼りになる。

■5. 3行まとめ

輸出管理は、だれに売ってよいかを国が決める仕組みである。
日本のレアアースは約6割が中国産で、1年止まれば損失は約2.6兆円との試算だ。
弱いGDPでも円は堅調で、実需の円買いが効いた。

■6. 試験対策の視点

輸出管理：どの国のだれに売ってよいかを国が決める
デュアルユース：軍民両用で使える品物
実需の円買い：決済のためにドルを売って円を買う動き
外務省の視点：中国以外の産地との関係づくりと、同じ悩みを持つ国との連携
経産省の視点：許可を出す役所であり、代替調達とリサイクルの支援も担う

■7. 今日の復習クイズ

問1　「輸出管理」の説明として正しいのはどれか。
ア　輸入品に税金をかけて国内産業を守る仕組み
イ　品物をどの国のだれに売ってよいかを国が決める仕組み
ウ　輸出と輸入の金額の差を計算した統計
エ　輸出企業が為替の損を防ぐ契約
【解答＝イ】関税は値段、輸出管理は売れるかどうかを決めます。

問2　中国がレアアースの対日輸出をしぼると、自動車生産が止まりかねない理由はどれか。
ア　レアアースが自動車の燃料だから
イ　円安になり部品が買えなくなるから
ウ　モーターの磁石の材料で、量はわずかでも代わりがきかないから
エ　高い関税で価格が上がるから
【解答＝ウ】なければ磁石が作れず、モーターも完成しません。

問3　（第3回）債券の値段が上がったとき、利回りはどうなるか。
ア　上がる
イ　下がる
ウ　変わらない
エ　円高のときだけ上がる
【解答＝イ】高く買うほど儲けの割合は小さくなります。

問4　（第7回）2026年6月の有効求人倍率はおよそどれか。
ア　0.88倍

【解答＝イ】求職者1人に1.18件の求人がある状態です。

問5　（第14回）EPA（経済連携協定）の説明として正しいのはどれか。
ア　特定の国どうしで関税を下げ、投資やルールでも協力を深める約束
イ　世界のすべての国に同じ関税率を義務づける条約
ウ　為替レートを一定の範囲に固定する取り決め
エ　資源を輸出しないと決める国どうしの申し合わせ
