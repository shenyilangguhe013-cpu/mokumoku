テーマ：実質金利と長期金利の上昇
利上げしても、実質ではまだマイナス。長期金利の上昇と、介入なしで155円を割った円高を図で整理します。

■1. 本日の一問

政策金利が1.00％、コアCPIが前年同月比1.8％のとき、実質金利はおよそいくらか。
ア　約マイナス0.8％
イ　約プラス0.8％
ウ　約プラス2.8％
エ　ゼロ
【解答＝ア】
実質金利：名目金利−物価上昇率
計算：1.00％−1.8％＝−0.8％
意味：利上げしても物価の伸びに追いつかず、お金は借りやすい

■2. つながりの流れ図

日銀の利上げペース加速観測 → 長期金利の先高観が強まる → 日米の金利差が縮むと意識される → 円が買われる
10年国債の入札 → 最高落札利回り3.011％ → 個人向け国債の金利が上がる → 国の利払い負担も重くなる
介入では守れた155円 → 市場の実勢だけで下抜けた → 金利差が縮めば円高は長続きしやすい
介入という力技でなく、実勢の力で節目を破った点が新しい角度です。

2026年9月9日 / 朝の東京は154円台前半。先週末比で200銭超の円高の場面も
3.011％ / 10年国債の入札の最高落札利回り
1.95％ / 個人向け国債の9月の利率（8月は1.87％）
約マイナス0.8％ / 日本の実質金利（概算）

■4. 国際比較・外部の視点

項目 / 日本銀行 / FRB（米国）
政策金利 / 1.00％ / 3.50〜3.75％
物価上昇率（7月・前年比） / 1.8％（コアCPI） / 3.4％（CPI）
実質金利（概算） / 約マイナス0.8％ / 約0.1〜0.35％
読み取り① 名目金利では日米とも引き締めに見えるが、実質では日本は大幅なマイナス圏だ。
読み取り② 実質金利がマイナスの間は、借りて投資する側に有利な環境が続く。

■5. 3行まとめ

実質金利は名目金利から物価上昇率を引いたもので、日本はまだマイナス圏だ。
長期金利は3％近くまで上昇。個人向け国債は9月に年1.95％の見通しだ。
ドル円は9月8日に155円を割り込み、一時154円05銭と半年ぶりの円高だ。

■6. 試験対策の視点

実質金利：名目金利から物価上昇率を引いた金利
最高落札利回り：国債の入札で決まった、いちばん高い利回り
個人向け国債：個人が買える国債。変動10年は金利に連動
外務省の視点：実質金利が低い円は借りやすく、キャリー取引が続きやすい
経産省の視点：名目の長期金利は上がり、中小企業の資金繰りに重荷がかかる

■7. 今日の復習クイズ

問1　「実質金利」の説明として最も正しいのはどれか。
ア　中央銀行が短期的に適用する特別な金利

ウ　為替介入の際に基準として使われる金利

【解答＝イ】名目金利から物価の上昇率を引いた金利です。

問2　日銀の利上げペース加速観測が強まると、円が買われやすくなる理由はどれか。
ア　日銀が直接、円を買う為替介入を行うから
イ　長期金利の先高観が強まり、日米の金利差が縮むと意識されるから
ウ　物価が下がって輸入コストが減るから
エ　政府が国債の発行をやめるから
【解答＝イ】金利差が縮むと、円が買われやすくなります。

問3　（第3回）債券の価格と利回りの関係として正しいのはどれか。

エ　利回りは常に一定で価格だけが動く
