テーマ：為替レートとは何か
為替の2つの見方と、日米協調介入が効いたのに戻った理由を図で整理します。

■1. 本日の一問

購買力平価の説明として、最も適切なものを選びなさい。
ア　同じ物なら、どの国でも同じ値段になるはずという考え方
イ　金利の高い国の通貨が必ず買われるという考え方
ウ　貿易黒字の大きさだけで為替が決まるという考え方
エ　政府が毎日決める交換比率
【解答＝ア】
ビッグマック480円 → 3.05ドルに換算 → 基準だと1ドル約78円 → 実際は約157円
購買力平価：長い目で見た為替の物差し
金利平価：金利差と予想が短い目の為替を動かす

■2. つながりの流れ図

円を買う介入 → 値段が直接動く → 金利差は変わらない → ドルを買う理由が残る → 水準が戻る
7月23日に163.988円 → 日米が協調介入 → 8月3日に155.218円 → 1週間で158円台へ
金利差1.00％対3.50〜3.75％ → ドルを持つ方が得 → 円売り・ドル買い → 円安の力が続く
介入は流れを止めるのでなく、時間を買う道具です。

■3. 年号・数字コーナー

1986年11月 / 7月23日の水準は、これ以来約40年ぶりの円安
2011年 / 実弾の日米協調介入が行われた（今回は15年ぶり）
2026年7月23日 / ドル円が一時163.988円をつけた
2026年7月31日 / 米財務省がNY連銀を通じて円買い介入
2026年8月3日 / 片山財務相が公表。ドル円は一時155.218円へ
2026年8月7日 / 東京市場で158円台まで戻した
480円 / 2026年1月の日本のビッグマックの価格
約78円 / ハンバーガー基準のドル（概算）
約9円 / 介入後に数営業日で動いた円高の幅

■4. 国際比較・外部の視点

中央銀行 / 政策金利 / 直近の動き
日本銀行 / 1.00％ / 6月に0.75％から利上げ
FRB（米） / 3.50〜3.75％ / 7月会合で据え置き（5会合連続）
ECB（欧） / 2.40％ / 6月に引き上げ
読み取り① 日本だけ1.00％と低く、金利差はまだ大きいままである。
読み取り② 米国は5会合連続の据え置きで、金利差が自然に縮む展開は描きにくい。

■5. 3行まとめ

為替レートは、長い目では購買力平価、短い目では金利平価で見る。
7月31日の日米協調介入は約9円の円高を作ったが、1週間で約3円戻った。
介入は金利差を変えないので、流れを止めず、時間を買う道具である。

■6. 試験対策の視点

為替レート：通貨と通貨の交換比率。1ドル157円など
購買力平価：ビッグマックで見ると1ドル約78円の概算
円買いの協調介入：28年ぶり。実弾の協調介入は2011年以来
外務省の視点：米国の協力は、通商交渉で見返りを求める材料になる
経産省の視点：円安で安く買われる企業・技術への警戒が要る

■7. 今日の復習クイズ

問1　7月31日の日米協調介入のあと、数営業日で円高に動いた幅は約何円か。
ア　約1円
イ　約3円
ウ　約9円
エ　約20円
【解答＝ウ】163円台から155円台へ、数営業日で約9円円高に振れました。

問2　介入で円高になっても、水準が戻りやすい理由はどれか。
ア　介入は禁止されているから
イ　日米の金利差は変わらず、ドルを買う理由が残るから
ウ　日本の物価が急に下がったから
エ　米国が政策金利を下げたから
【解答＝イ】介入は値段を動かしても、金利差までは変えられません。

問3　（第4回）日銀が動かす政策金利の説明として正しいものはどれか。
ア　銀行どうしが1日だけ貸し借りする金利
イ　住宅ローンの固定金利
ウ　10年国債の利回り
エ　預金の最低金利
【解答＝ア】日銀は、この短期金利を目標の水準へ誘導します。

問4　（第3回）国債が売られて値下がりすると、利回りはどうなるか。
ア　上がる
イ　下がる
ウ　変わらない
エ　ゼロになる
【解答＝ア】価格と利回りは逆に動くので、値下がりすると利回りは上がります。

問5　（第2回）為替が動く理由として正しいものはどれか。
ア　実際の政策変更だけで動く
イ　金利差の予想の変化でも動く
ウ　CPIの発表日にだけ動く
エ　貿易統計でだけ動く
【解答＝イ】為替は、実際の政策より先に予想で動くことがあります。
