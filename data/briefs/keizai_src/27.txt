テーマ：ターミナルレートと日米の利上げ観測
利上げはどこまで続くのか。日米の利上げ観測と円の動きを図で整理します。

■1. 本日の一問

政策金利1.00％から0.25％刻みの利上げで2.50％に届くには、何回の利上げが必要か。
ア　6回
イ　4回
ウ　5回
エ　8回
【解答＝ア】
今の水準：1.00％
市場の織り込み：2.50％
差：1.50％÷0.25％＝6回

■2. つながりの流れ図

日銀の利上げ観測が強まる → 日米の金利差が縮むと意識される → 円が買われる → ドル円は155円台へ
介入の効果は一時的 → 日銀が利上げを続けられるかが本質 → 到達点の読みで円の勢いが変わる
物価の勢いを読み違える → 政治家と中央銀行が対立する → 独立性が試される
貿易の実需のドル買いは、介入後も下支えを続けています。

■3. 年号・数字コーナー

2026年6月 / ECBが2年9か月ぶりに利上げした
2026年7月中旬 / ドル円が一時164円台まで進んだ
2026年7月31日 / 日米協調介入で155円台へ急落
2026年9月7日 / 午前のドル円が155円81銭まで下落
2026年9月17〜18日 / 日銀の会合。利上げが有力
1.75％ / 三井住友DSアセットの想定する到達点
2.50％ / 市場が織り込む到達点
8割 / 市場が織り込む9月の利上げ確率

■4. 国際比較・外部の視点

項目 / 日本銀行 / FRB（米） / ECB（欧）
政策金利 / 1.00％ / 3.50〜3.75％ / 2.25％
現在の焦点 / 9月に利上げが有力 / 9月FOMCで利上げ論も浮上 / 6月に利上げ、7月は据え置き
読み取り① 主要中銀の多くが、利下げでなく引き締め方向を探っている。
読み取り② 米国は政治との対立が最も激しく、独立性の緊張が先鋭化している。

■5. 3行まとめ

ターミナルレートは利上げの最終到達点で、日銀は市場で2.50％まで織り込まれつつある。
米国でもFRBに利上げ観測が浮上し、トランプ大統領との綱引きが続く。
ドル円は協調介入後も一進一退で、9月7日には155円台まで円高が進んだ。

■6. 試験対策の視点

ターミナルレート：利上げが最終的にたどり着く政策金利の水準
利上げの刻み：日銀は通常0.25％ずつ
織り込み：今の予想を価格に入れること。確定した未来ではない
外務省の視点：財務長官の発言や協調介入という政治レベルの動きが市場を動かす
経産省の視点：円が155〜156円台に戻ると輸出企業の採算に逆風になる
