@@@ISSUE 7 | 2026-08-09 | 失業率と有効求人倍率
テーマ：失業率と有効求人倍率
失業率が下がったのに、ドルが売られた日。その理由を図で整理します。

■1. 本日の一問

完全失業率の分母として、正しいものを選びなさい。
ア　国民全体の人数
イ　働く人と職を探す人の合計
ウ　就業者だけの人数
エ　15歳以上の人口
【解答＝イ】
参加者だけを数える → 学生や専業主婦は含まれない → あきらめた人は分母から消える → 失業率が下がる
完全失業率：失業者÷労働力人口
有効求人倍率：求人数÷求職者数

■2. つながりの流れ図

就業者6890万人 → 完全失業者178万人 → 合計が労働力人口 → 失業率は約2.5％
米雇用者数が2.3万人減る → 利下げの予想が強まる → ドルの金利が下がりそう → 円高
職探しをやめた人が増える → 分母が減る → 失業率が下がる → 数字は改善して見える
市場が重く見るのは、失業率ではなく雇用者数のほうです。

■3. 年号・数字コーナー

2026年6月 / 日本の完全失業率は2.5％、有効求人倍率は1.18倍
2026年7月 / 米非農業部門雇用者数が2.3万人減（予想は8万人増）
2026年7月31日 / 総務省が6月の労働力調査を発表
2026年8月7日 / 米7月雇用統計の発表後、ドル円が一時156.68円へ急落
2027年4月 / 育成就労制度が始まる予定
6890万人 / 日本の就業者数（2026年6月）
178万人 / 完全失業者数。11か月連続で増加
6.3％ / ユーロ圏の失業率（統計開始以来の最低水準）

■4. 国際比較・外部の視点

国・地域 / 失業率 / 時点
日本 / 2.5％ / 2026年6月
米国 / 4.1％ / 2026年7月
ユーロ圏 / 6.3％ / 2026年6月
読み取り① 日本の低さは、働き手そのものが減っていることの裏返しでもある。
読み取り② ユーロ圏は統計開始以来で最低だが、国ごとの差が大きい。

■5. 3行まとめ

完全失業率の分母は、働く人と職を探す人。あきらめた人は数から消える。
6月の日本は失業率2.5％・有効求人倍率1.18倍で、人手不足が続く。
米国は失業率が下がっても、雇用者数の減少でドルが売られた。

■6. 試験対策の視点

完全失業率の分母：労働力人口（働く人＋職を探す人）
有効求人倍率：求人118件÷求職者100人＝1.18倍
米雇用統計：2つの調査。市場は事業所調査を重視
外務省の視点：人手不足は外国人受け入れ交渉につながる
経産省の視点：賃上げの価格転嫁の支援と省力化投資が焦点

■7. 今日の復習クイズ

問1　2026年6月の日本の完全失業率に最も近いものはどれか。
ア　1.5％
イ　2.5％
ウ　3.5％
エ　4.5％
【解答＝イ】2.5％で、前の月と同じでした。

問2　有効求人倍率が1倍を超えているときの状態はどれか。
ア　仕事の口より、探す人のほうが多い
イ　仕事の口のほうが、探す人より多い
ウ　失業者がいない
エ　賃金が必ず上がる
【解答＝イ】求人数が求職者数を上回っている状態です。

問3　（第6回）海外投資の配当・利子が計上される収支はどれか。
ア　貿易収支
イ　サービス収支
ウ　第一次所得収支
エ　第二次所得収支
【解答＝ウ】第一次所得収支は、海外に持つ株や工場からの稼ぎです。

問4　（第5回）購買力平価の説明として正しいものはどれか。
ア　同じ物なら、どの国でも同じ値段になるはずという考え方
イ　金利の高い通貨が必ず買われるという考え方
ウ　政府が毎日決める交換比率
エ　貿易黒字だけで決まる考え方
【解答＝ア】ビッグマックで比べるのが分かりやすい例です。

問5　（第4回）日銀が動かす政策金利の説明として正しいものはどれか。
ア　銀行どうしが1日だけ貸し借りする金利
イ　住宅ローンの固定金利
ウ　10年国債の利回り
エ　預金の最低金利
【解答＝ア】日銀は、この短期金利を目標の水準へ誘導します。
