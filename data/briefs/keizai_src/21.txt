@@@ISSUE 21 | 2026-08-24 | 対内直接投資
テーマ：対内直接投資
外国企業が日本に工場や会社を持つこと。日本の低さとソニー・TSMCの熊本投資を図で整理します。

■1. 本日の一問

日本の対内直接投資残高のGDP比と、OECD38か国の中での位置として正しいのはどれか。
ア　5％で、最下位
イ　27％で、中位
ウ　67％で、平均並み
エ　14％で、上位
【解答＝ア】
対内：外国から日本の中へ入ってくる投資
対外：日本から海外へ出ていく投資
日本の残高：GDPに対して5％。OECDの平均は67％

■2. つながりの流れ図

TSMCが資金と技術を持ち込む → ソニーと合弁会社を作る → 熊本に工場ができる → 雇用と技術が地元に広がる
米国の長期金利が上がる → ドルで持つと利息が多い → 円を売ってドルを買う → 円安・ドル高
外国から投資を集める → 供給網の海外依存を減らす → 経済安全保障が強まる
金利差のドル買いは、訪日客の円買いより今週は強く出ました。

■3. 年号・数字コーナー

2020年末 / 対内直接投資残高の対GDP比は日本が5％
2026年8月11日 / ソニーとTSMCが熊本に合弁会社を設立すると発表
2026年8月21日 / ドル円は159円14銭。米10年債の利回りは4.70％
2026年8月27〜29日 / ジャクソンホール会議。パウエルFRB議長が講演予定
2029年 / 熊本の新工場で量産を始める計画
2030年 / 対内直接投資残高を120兆円にする政府目標
約7,470億円 / ソニーとTSMCが出す資金の合計
1兆円規模 / 補助金を含めた総投資額の見通し

■4. 国際比較・外部の視点

国・地域 / 残高のGDP比（2020年末） / ひとこと
日本 / 5％ / OECDで最下位
韓国 / 14％ / 隣国でも日本の約3倍
ドイツ / 27％ / 日本の5倍超
OECD平均 / 67％ / 日本の大きく上
読み取り① 日本は経済大国なのに、投資を集める力は際立って低い。
読み取り② 政府は2030年に120兆円を掲げ、TSMCとソニーはその代表例である。

■5. 3行まとめ

対内直接投資は外国企業が日本国内に事業を持つことで、日本の残高はGDP比5％と最下位だ。
ソニーとTSMCが熊本に1兆円規模で投資し、2029年に量産を始める。
今週のドル円は、日米金利差のドル買いが訪日客の円買いより強く出た。

■6. 試験対策の視点

対内直接投資：外国企業が日本に工場を建てる、出資するなど
対外直接投資：日本企業が海外に工場を建てるなど。向きが逆
キャリー取引：金利の低い通貨を売り、高い通貨で運用する取引
外務省の視点：投資協定やEPAで安心して投資できる国だと保証する
経産省の視点：半導体は重要物資。補助金で国内の生産基盤を強くする

■7. 今日の復習クイズ

問1　対内直接投資の説明として正しいのはどれか。
ア　日本企業が海外に工場や支店を作ること
イ　外国企業が日本国内に工場や会社を作ったり、出資したりすること
ウ　外国人が日本の国債を売買すること
エ　日本政府が海外に援助資金を送ること
【解答＝イ】アは逆方向の対外直接投資です。

問2　米国の長期金利が上がるとドルが買われやすい理由はどれか。
ア　米国の物価が下がるから
イ　ドルで運用すると利息が増え、円を売ってドルを買う動きが増えるから
ウ　米国政府の借金が減るから
エ　日銀が自動的に円を売るから
【解答＝イ】金利が高い通貨で持つほうが得なので、ドルが買われます。

問3　（第1回）GDP（国内総生産）の説明として正しいのはどれか。
ア　その国の1年間の売上の単純合計
イ　その国で1年間に新しく生み出された付加価値の合計
ウ　政府が保有する貯金の総額
エ　国民1人あたりの給料の平均
【解答＝イ】仕入れを差し引いた、新しく生んだ価値の合計です。

問4　（第19回）2024年の日本の時間当たり労働生産性は、OECD38か国中で何位か。
ア　5位で78.4ドル
イ　15位で68.2ドル
ウ　28位で60.1ドル
エ　35位で42.7ドル
【解答＝ウ】主要先進国の中では低い水準です。

問5　（第3回）短期金利と長期金利は、それぞれ誰が決めるか。
ア　短期は市場、長期は日本銀行
イ　短期は日本銀行、長期は市場
ウ　どちらも日本銀行
エ　どちらも市場
【解答＝イ】政策金利は日銀が決め、長期金利は市場での売買で決まります。
