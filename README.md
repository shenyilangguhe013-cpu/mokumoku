# もくもく部屋

一人だと勉強を後回しにしてしまう大学生向けの、スマホ用「もくもく学習」アプリです。
架空の大学生ライバルたちが同じ部屋で勉強している気配を再現し、ワンタップで勉強を始められることを目指しています。

`index.html` 1ファイルだけで完結しており、外部ライブラリやビルド手順は不要です。

## 主な機能

- **もくもく部屋（メイン画面）**
  架空のライバル6人（うち1人は夜型で15:00〜翌3:00に活動）が、それぞれの学年・学部・目標に応じて「勉強中（経過分）」「休憩中」「退室中」を切り替えながら過ごしています。状態はイラスト風のアバター（机に向かってペンを動かす／一息ついている／席が空いている）で表現され、勉強中はペンの動きと体の上下動が分かりやすいよう大きめに表示されます。動きは日付をシードにした疑似乱数で決まるため、同じ日にリロードしても状態は一貫します。部屋⇄タイマー画面の切り替えにはふわっとした遷移アニメーションを付けています。
- **ワンタップで入室**
  「大学の課題」「資格の勉強」から選び、時間（15分・25分・50分、初期値25分）を選ぶだけで開始できます。「資格の勉強」を選んだときのみ、メモ欄の上に科目のプルダウン（第1次試験対策・時事系・専門法律系・第2次試験対策の4区分・未選択・自由入力も可）が表示されます。開始すると自分も部屋に「勉強中」として表示され、タイマーが進みます。目標時間を過ぎても自動終了せず「+◯分」の延長表示のまま測り続けるので、キリの良いところで「切り上げて終了する」を押してください。途中で終了した場合も、その場合の経過時間がそのまま記録されます。
- **競争要素**
  今日・今週の勉強時間ランキングを、自分＋ライバルで表示します。大学生の平均学習時間（仮の基準値、コード冒頭で設定）を超えた日は、その旨が表示されます。
- **先週の自分との比較**
  「今週」タブで、今週と先週の曜日別勉強時間を棒グラフ（自作SVG）で比較できます。増えていれば強調表示し、減っていても責めない表現にしています。
- **連続入室日数（ストリーク）**
  部屋タブに「連続◯日入室中」を表示し、継続のモチベーションを可視化します。今日まだ記録がなくても、その日のうちは連続記録をリセットしません。
- **完了コマ数の記録**
  「資格の勉強」で科目を選んで終了すると、完了画面に「この時間で完了したコマ数」のステッパー（−/+、初期値0）が表示されます。0のまま閉じても構いません。「大学の課題」や科目未選択のときは表示されません。
- **データの書き出し・読み込み・削除**
  「データ」タブから、記録をJSONファイルとして書き出し・読み込みできます。書き出したJSONの各記録には、選んだ科目名（未選択の場合は空文字）が `subject` キーとして、完了コマ数が `completedUnits` キー（0以上の整数、デフォルト0）として必ず含まれます。読み込みは既存データに追加され、上書きはされません。誤って記録した項目は履歴一覧の「✕」から個別に削除できます。
- **GitHubへの直接保存（任意）**
  「データ」タブの「GitHub連携」から、このリポジトリ専用のGitHub Personal Access Token（Fine-grained・Contents: Read and write権限のみ）を登録すると、「GitHubに保存」ボタンでエクスポートJSONと同じ内容を `data/mokumoku_export.json` に直接コミットできます。ダウンロード式の書き出しはバックアップとしてそのまま使えます。トークンは端末のlocalStorageに保存されるため、端末を紛失・売却・共有する場合はGitHub側でトークンを失効させてください。
- **学習記録を手動で追加**
  「データ」タブの「学習記録を手動で追加」から、タイマーを使わずに過去の学習を記録できます。「大学の課題」「資格の勉強」の種別、（資格の勉強のときのみ）科目、日付、学習時間（時間・分）、完了コマ数（科目選択時のみ・任意）、メモを入力して「記録を追加」を押すと、通常のタイマー終了と同じ形式の記録として履歴に追加されます。
- **科目別の進捗**
  「データ」タブの「科目別の進捗」に、資格の勉強の21科目それぞれについて、進捗管理シート（新学習計画_2026.xlsx）の総回数・基準日時点の完了コマ数をもとにした「完了数/総数」の進捗バーを表示します。基準日（`SUBJECT_BASELINE_DATE`）より後の日付で記録した完了コマ数だけが基準値に加算されるため、進捗管理シート側の集計と二重にカウントされません。この一覧にない科目名で記録した完了コマ数は、合計コマ数として別途注記されます。
- **節目の達成演出**
  連続入室日数が3・7・14・30・50・100・200日に達した日は、完了モーダルにいつもと違う特別なメッセージ（🎖️）が表示されます。また、完了コマ数の累計が10・30・50・100・200・500コマに達したタイミングでは、お祝いのトーストが表示されます。頻度を絞ることで、毎回の演出が安っぽくならないようにしています。
- **「今日はまだ」の優しい一言**
  17時以降、その日まだ記録がなく、かつタイマーを起動していない場合のみ、部屋タブに控えめな一言（「今日はまだ記録がありません。少しだけでも始めてみませんか？」）を表示します。責める表現は使わず、アプリを開いた人にだけ届く弱いリマインドです。

## 使い方

1. `index.html` をスマホのブラウザで開きます（下記のGitHub Pagesでの公開方法が簡単です）。
2. 「部屋」タブで「大学の課題」または「資格の勉強」をタップし、時間を選んで「この内容で始める」をタップすると学習タイマーが始まります。
3. タイマーが終わると、今日の合計勉強時間とともに労いメッセージが表示されます。
4. 「ランキング」タブで今日・今週の順位を、「今週」タブで先週との比較グラフを確認できます。
5. 「データ」タブから、記録のバックアップ（書き出し）や、他端末で書き出したデータの読み込みができます。

データはすべて端末のlocalStorageに保存されるため、ブラウザのデータを消去すると記録も消えます。定期的にJSONで書き出しておくことをおすすめします。

## GitHub Pagesでの公開手順

1. このリポジトリのGitHub設定画面で **Settings > Pages** を開きます。
2. 「Build and deployment」の Source を **Deploy from a branch** に設定します。
3. Branch を公開したいブランチ（例: `main`）、フォルダを `/(root)` に設定して保存します。
4. しばらく待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。
5. スマホでそのURLを開き、ブラウザの共有メニューから「ホーム画面に追加」を選ぶと、アプリのように使えます。

## 基準値について（要確認）

`index.html` 冒頭の `BASELINE_AVG_MINUTES` は、大学生の平均的な1日の学習時間を表す仮の基準値です。出典を明記したコメントを付けていますが、実際のデータに後で差し替える前提の値です。ライバルの学習量は、この基準値に一人ひとり0.7〜1.5倍程度の個人差と、日ごとのばらつきを掛け合わせて算出しています。また、ライバルの1日のスケジュールは「退室中（未着手・空き時間）」の時間帯が大半を占めるように、開始時刻を日中に幅広く散らし、学習ブロックの間の空き時間も長めに取っています。常にライバル全員が高い学習量を積み上げているように見えると比較がしんどくなるため、この点は意図的に調整しています。
