テーマ：関税とEPA（経済連携協定）
関税は相手を打つ棒であり、自分の足も踏む道具。米国とカナダの交渉を図で整理します。

■1. 本日の一問

EPA（経済連携協定）の説明として、最も適切なものを選びなさい。
ア　国どうしが互いの関税を下げ、投資や人の移動のルールもまとめて決める条約
イ　輸入品にだけ課す一方的な追加関税
ウ　為替レートを固定する取り決め
エ　国際機関への分担金の約束
【解答＝ア】
関税：国境をまたぐ荷物にかかる税金
EPA：関税に加え、投資・サービス・人の移動も決める
CPTPP：多国間でルールを広げる枠組み

■2. つながりの流れ図

関税をかけると予告 → 相手が交渉の席に着く → 発動前に譲歩を引き出す
関税を上げる → 輸入側の売値がまず上がる → 自国の企業と消費者が負担する
日銀の9月利上げ報道 → 市場はすでに見込んでいた → 新しい情報がない → 円はほとんど動かない
関税は、かけると言った状態がいちばん交渉力を持ちます。

■3. 年号・数字コーナー

2025年9月 / 日本からの輸入品に一律15％とする特例の大統領令
2026年5月6日 / CPTPPでコスタリカの加入交渉が実質妥結
2026年7月20日 / 米国がカナダ産に338条で50％の追加関税を布告
2026年7月24日 / 301条によるカナダ産品への10％追加関税を開始
2026年8月13日 / カナダ担当相が米USTR代表と4回目の閣僚級会談
2026年8月19日 / 338条の関税の発動予定日
15万円 / 100万円の日本車に関税15％がかかったときの税額
50％ / 338条に基づく追加関税の税率

■4. 国際比較・外部の視点

枠組み / 2026年の動き / 見るところ
CPTPP / 英国が加入、コスタリカは実質妥結 / 多国間でルールを広げる
日米 / 日本からの輸入に一律15％ / 二国間の個別の取り決め
米・カナダ / 301条10％、338条50％ / 発動前の交渉が焦点
読み取り① ルールを多国間で広げる動きと、力で個別に決める動きが同時に進む。
読み取り② 関税は、発動しないこと自体が交渉カードになる。

■5. 3行まとめ

関税を納めるのは輸入する側で、相手だけでなく自国の消費者にも効く。
米国はカナダに301条で10％、338条で50％。発動前に4回目の閣僚級協議が行われた。
ドル円が159円台でも、日銀の利上げ報道は織り込み済みで動きが小さい。

■6. 試験対策の視点

関税：輸入する側が自国の税関に納める税金
EPA：互いの関税を下げ、投資や人の移動も決める条約
織り込み：予想が先に値段へ入っている状態
外務省の視点：二国間で押されると譲歩が積み上がる。CPTPPで後ろ盾を作る
経産省の視点：部品が何度も国境を越える自動車産業は、工程の組み替え支援が要る

■7. 今日の復習クイズ

問1　関税を実際に納めるのは誰か。
ア　輸出した国の政府
イ　輸出した会社
ウ　輸入する側の会社が、自国の税関に納める
エ　商品を買った海外の消費者が直接納める
【解答＝ウ】関税を上げると、まずその国の売値が上がります。

問2　日銀の9月利上げ報道でも円が大きく買われなかったのはなぜか。
ア　日銀がすぐ否定したから
イ　利上げはもともと円安の材料だから
ウ　市場がすでに9月か10月の利上げを見込んでいたから
エ　米国が同時に利下げを決めたから
【解答＝ウ】織り込み済みのニュースには新しい情報がなく、相場は動きません。

問3　（第1回）名目GDPと実質GDPの違いはどれか。
ア　名目GDPが物価の変動を除いたもの
イ　実質GDPが物価の変動を除いたもの
ウ　名目GDPは海外での生産も含む
エ　実質GDPは年率に換算したもの
【解答＝イ】実質GDPは物価の上下を取り除いた量の伸びを見ます。

問4　（第3回）市場の金利が上がると、発行済みの債券の価格はどうなるか。
ア　上がる
イ　下がる
ウ　変わらない
エ　満期日まで動かず、満期日に上がる
【解答＝イ】新しい債券のほうが利息が多いので、古い債券は値下がりします。

問5　（第7回）2026年6月の有効求人倍率はいくつか。
ア　0.98倍
イ　1.18倍
ウ　1.38倍
エ　1.58倍
【解答＝イ】求職者1人あたり1.18件の求人がある状態です。
